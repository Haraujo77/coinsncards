# Examples

- **`theme.css`** — the full `@theme inline` setup: dark + light token pairs, the
  three control surfaces, themed shadows, and the scrollbar reset. The `@font-face`
  block at the top is artboard-only (brand faces) and is safe to delete.
- **`params.ts`** — a real parameter table. Every inspector row, default, per-group
  reset, changed-from-default cue and the JSON export generate from this one file.
  Numeric values are typed fields (click to edit, drag to scrub), not slider-only.
